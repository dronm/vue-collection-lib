# Examples

- `basic-crud/` contains a typed API, a routed `CollectionGrid`, a `ReferenceInput`, and a create/edit/copy form using Valibot and `useCollectionFormSubmit()`.
- `nuxt/plugins/collection-lib.client.ts` shows client-only WebSocket setup for Nuxt.

The route names and backend paths are placeholders. Copy the relevant files into an application and adapt them to its models, routes, API contract, and translations.
